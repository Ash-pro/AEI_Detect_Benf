# AEI Detect Benf — تصميم الواجهات (المرحلة 1: الاستخدام اليومي)

واجهات Next.js + Tailwind (RTL) ببيانات تجريبية في الذاكرة. لا يوجد Supabase بعد.
المرجع: `ANALYSIS.md`.

## التشغيل

```bash
npm install
npm run dev
# http://localhost:3000
```

## مسار المعاينة

1. `/setup` اختر المركز وأدخل أي رمز أدمن من 4 أرقام.
2. `/login` اختر حساب معاينة (كلمة المرور `1234`):
   - `reception1` استقبال
   - `unicef1` موظف مشروع UNICEF
   - `multi1` موظف مشروعين WFP + السيلياك (تظهر شاشة اختيار المشروع)
3. `/verify` استخدم "سيناريوهات المعاينة" أسفل حقل الهوية.

لإعادة الإعداد: امسح Local Storage للموقع.

## مفاتيح الميزات

`lib/features.ts`: `excelUpload: false` يخفي رفع Excel وسجل الرفعات من القائمة ويحوّل مساراتهما إلى `/verify`. لإظهارهما: `true`.

## البنية

```
app/                 الصفحات
components/ui/       العناصر الأساسية (Button, Card, Chip, Dialog, Field, Badge)
components/shell/    الهيدر، حماية الجلسة، تخطيط شاشات الدخول
components/verify/   مكونات واجهة التحقق
lib/mock-data.ts     بيانات تجريبية (تُستبدل بـ Supabase)
lib/logic.ts         منطق العرض (سيُنقل لدوال Postgres)
lib/session.tsx      جلسة وبيانات في الذاكرة
```

الألوان كلها Tokens في `app/globals.css` و`tailwind.config.ts` (لون لكل مركز: غزة Teal، خانيونس Violet).
