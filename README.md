# AEI Detect Benf — تصميم النظام (الإصدار 3.0)

تصميم كامل للواجهات حسب التحليل 3.0، مربوط بـ Supabase (قاعدة البيانات وتسجيل الدخول والتحديث اللحظي) ومنشور على Vercel.

## التشغيل

```bash
npm install
npm run dev
# http://localhost:3000
```

## قاعدة البيانات (Supabase)

- المشروع: `AEI_Detect_Benf` — المتغيرات في `.env.local` وعلى Vercel:
  `NEXT_PUBLIC_SUPABASE_URL`، `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY`، `SUPABASE_SECRET_KEY` (سري، للخادم فقط).
- كل تغييرات قاعدة البيانات في `supabase/migrations`.
- تسجيل الدخول باسم المستخدم، ويُحوَّل داخلياً إلى `username@aei.local` في Supabase Auth.
- الحسابات تُنشأ من لوحة التحكم ← المستخدمون (الأدمن، والمشرف للاستقبال والنقاط).
- رقم الدور يُحسب داخل قاعدة البيانات، وقائمة الانتظار تتحدث لحظياً (Realtime).
- القراءة محكومة بصلاحيات RLS حسب الدور والمركز والمشروع، والكتابة فقط عبر دوال قاعدة البيانات.

## قواعد الإدخال

- رقم الهوية: الشرط الوحيد 9 أرقام بالضبط.
- الحالة الجديدة: الاسم مطلوب (الأول يكفي، أو الأول والثاني) + نوع الهوية أب / أم / طفل. يعدّلهما الموظف من زر "تعديل".
- رقم الدور: يبدأ من 1 كل يوم، مستقل لكل مشروع في كل مركز، ويُعطى عند تحويل الاستقبال. المشروع المضاف لاحقاً يأخذ الرقم التالي، والرقم الملغى لا يُعاد استخدامه.
- النقطة تخدم من قائمة الانتظار: الضغط على الحالة يفتحها ويربط الخدمة بدورها، حتى لو أُدخلت بهوية الطفل بدل ولي الأمر.
- موظف النقطة يدخل الخدمة في مشروعه فقط، ويرى بوضوح هل الحالة محوّلة لمشروعه أم لمشروع آخر.
- التوجيه الخاطئ: موظف النقطة يضغط "التوجيه خاطئ؟ تعديل التوجيه" ويختار المشروع الصحيح من كل المشاريع، دون الرجوع للاستقبال ودون تسجيل خدمة. إن كان أدخل خدمة بالخطأ يُحذف إدخاله في نفس الخطوة. نقطة المشروع الصحيح ترى الحالة في قائمة انتظارها برقم دور جديد مع ملاحظة "محوّلة من…"، وقائمة المشروع الأول تعرضها "حُوّلت".
- لا يُسمح بإدخال نفس الهوية لنفس المشروع مرتين في نفس اليوم في النقاط.

## PWA (تطبيق قابل للتثبيت)

- `app/manifest.ts` ملف التطبيق، والأيقونات في `public/icons`، و`public/sw.js` يخزّن واجهة التطبيق فقط (الصفحات بالشبكة أولاً، ولا بيانات مستفيدين).
- زر "تثبيت" جانبي يظهر على الجوال والتابلت فقط، ويختفي بعد التثبيت. يمكن إخفاؤه 3 أيام بزر ×.
- على Android/Chrome يفتح نافذة التثبيت مباشرة. على iPhone يعرض خطوات "إضافة إلى الشاشة الرئيسية" من Safari.
- التثبيت يحتاج رابطاً آمناً https (مثل Vercel) أو `localhost`. على رابط الشبكة المحلية `http://192.168.x.x` لن يظهر خيار التثبيت.

## ملاحظات التصميم

- البيانات تُحفظ في Local Storage لهذا المتصفح فقط. كل يوم جديد تُولَّد إدخالات تجريبية جديدة، ويبقى المستخدمون والمشاريع والإعدادات.
- "إعادة البيانات التجريبية" من صفحة الإعدادات ترجع كل شيء للبداية.
- أزرار تصدير Excel تصميم فقط، وتعمل بعد ربط قاعدة البيانات.
- قائمة "أمثلة للاختبار" تحت حقل الهوية للعرض فقط وتُحذف عند الربط.

## وضع العرض التجريبي (للمراجعة المحلية فقط)

```bash
NEXT_PUBLIC_DEMO=1 npm run dev
```
يشغّل الموقع ببيانات وحسابات تجريبية في المتصفح بدون Supabase (كلمة المرور `1234`، مثل `admin` و`reception.khy` و`multi.khy`). لا يُستخدم على Vercel.
